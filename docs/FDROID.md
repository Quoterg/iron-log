# F-Droid notes

Iron Log's Android app is a Trusted Web Activity (TWA) wrapper around the web app (see
`android/README.md`). Things to know before submitting to F-Droid:

- **License and source:** the app is AGPL-3.0 and fully open; the wrapper is generated by
  Bubblewrap (Apache-2.0) from `android/twa-manifest.json`. F-Droid builds from source, so the
  generated Gradle project must be committed (run `bubblewrap update` and commit `android/`
  except the keystore) for its build server to build it.
- **Dependencies:** the TWA uses `androidx.browser` (open source). It needs a browser that
  supports TWAs or Custom Tabs on the device; it falls back to Custom Tabs otherwise. There are no
  Google Play Services, analytics or ad libraries.
- **Network:** the app's code and food data come from the website (GitHub Pages) and barcodes are
  looked up at Open Food Facts. F-Droid lists such behaviour under anti-features where it applies;
  expect at least a review of whether "NonFreeNet" applies (the services themselves are open data
  / open source, which usually means it does not).
- **Alternative without any wrapper:** users can install the PWA directly from the browser
  ("Add to home screen"); this is the recommended path for de-Googled phones and needs no store.

Metadata for F-Droid (`metadata/io.github.quoterg.ironlog.yml` in fdroiddata) can reuse the
texts in `docs/STORE-LISTING.md`.
